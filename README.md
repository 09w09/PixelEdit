# PixelEdit

面向 **400×300 黑白像素屏** 的网页像素编辑器。

## 在线使用

https://09w09.github.io/PixelEdit/

## 本地开发

需要 Node.js 20+。

```bash
git clone https://github.com/09w09/PixelEdit.git
cd PixelEdit
npm install
npm run dev
```

终端会输出本地访问地址，通常为 `http://localhost:5173/`。

## 构建

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`。
